# Fuentes del protocolo

Solo se almacenan aquí documentos públicos con licencia compatible y un
registro en `manifest.csv`. Los documentos con licencia pendiente o acceso
restringido deben permanecer en `data/raw/documentation/`, fuera de Git.

El informe OECD se conserva con su nombre normalizado; `manifest.csv` mantiene
el DOI, la licencia CC BY 4.0 y el SHA-256 del archivo original.
