# Plantillas de armonización

Estas plantillas definen los campos mínimos antes de poblar los catálogos
canónicos. Los nombres de campo son estables, en inglés y `snake_case`.

- `dataschema-template.csv`: una fila por variable objetivo definida
  independientemente de las fuentes.
- `equivalence-matrix-template.csv`: una fila por combinación de variable
  objetivo y fuente concreta.

Los valores de ejemplo no se incluyen para evitar que una plantilla vacía se
interprete como mapping aprobado. Las listas controladas se documentan en el
protocolo y deben validarse antes de importar filas a los catálogos.
